# Редактор контент-планов

Изменение раскладки существующего P0. Документ Word использован как визуальный и содержательный ориентир, его инструкции не считаются самостоятельными командами. Исходный DOCX не изменён. Текст и доступные изображения проверены через OOXML; полный рендер страниц Word не выполнялся. Одно встроенное изображение имеет ошибку CRC, поэтому оно не использовалось для визуальной проверки.

## Раскладка

| Ширина окна           | Навигация                        | Документ               | Свойства                 |
| --------------------- | -------------------------------- | ---------------------- | ------------------------ |
| 1440 px               | 220 px, sticky outline           | около 880 px           | 260 px, sticky inspector |
| 1920 px               | 280 px                           | максимум 1050 px       | 320 px                   |
| 768–1199 px           | кнопка «Структура», панель слева | основная область       | панель справа            |
| меньше 768 px         | сворачиваемая панель             | ширина доступного окна | нижний лист              |
| Предпросмотр / viewer | скрыта                           | максимум 1160 px       | скрыты                   |

Слева — обложка, заголовки, задачи, референсы, изображения и заметки; активный блок подсвечен. Навигация прокручивает документ, текстовые блоки получают курсор. Вставка доступна для заголовка, задачи, референса, изображения, заметки и разделителя. Slash menu и встроенные handles BlockNote сохранены. Отдельный drag-and-drop в outline не добавлен.

Задачи читаются без инспектора: заголовок, статус, описание и требования, синие ссылки, красный дедлайн, жирная строка ответственных, приоритет. Портретные референсы стоят справа при ширине от 768 px и ниже текста на телефоне. Редактор, предпросмотр, импорт, история и viewer используют те же компоненты документа.

## Совместимость

- Поля `Task`, `props.taskId`, свойства референсов/изображений и BlockNote schema сохранены. `schemaVersion` остаётся 1.
- База Dexie, таблицы, autosave, очередь записи, контроль конфликта вкладок, импорт, export, revisions и share codec не изменены.
- Формат, FPS и технические требования вводятся в существующее описание. Несколько ответственных записываются в существующую строку `assignee`; новых сущностей или полей нет.
- Последовательные reference/image сразу после задачи визуально объединяются с её брифом. `taskCompanions` вычисляет это представление без изменения порядка, ID, props, children или связей переносимого документа. Между ними не должно быть другого блока. Блоки медиа с children остаются самостоятельными, чтобы не скрывать вложенное содержание. Удаление задачи раскрывает следующие медиа как самостоятельные блоки; undo возвращает прежний вид.
- В инспекторе свойства медиа меняются через `editor.updateBlock`, удаление — через `editor.removeBlocks`. Обработчики сохранения получают исходные блоки BlockNote, а не визуально собранный бриф.
- Название обложки связано с существующим `plan.title`. Статистика считает уникальные задачи и готовые задачи.
- Обложка и watermark используют только существующий `/icon.svg`. Переключатель watermark — состояние текущего экрана, не поле JSON или настройка базы. Shared viewer показывает стандартный слабый watermark независимо от переключателя автора.
- Пользовательские изображения из Word и тестовый контент не добавлены в исходники, demo seed или production. Для визуальных проверок использован отдельный браузерный контекст и перехват URL изображений.

## Сверка с концептом

| Ориентир              | Реализация / намеренное отличие                                                       |
| --------------------- | ------------------------------------------------------------------------------------- |
| Три рабочие зоны      | Навигация, ограниченная ширина документа, инспектор; ширины проверены в браузере      |
| Редакционная иерархия | Крупный заголовок обложки, нумерованные заголовки задач, текст без вложенных карточек |
| Референс справа       | Исходные портретные изображения, ниже текста на телефоне                              |
| Цветовые акценты      | Синие ссылки и разделители, красный дедлайн, жирные ответственные                     |
| Выбор и свойства      | Лёгкая рамка только у выбранного блока; поля вынесены в инспектор                     |
| Чистый просмотр       | Один renderer, максимум 1160 px, без панели вставки, handles и полей ввода            |

Текст, люди и фото, нарисованные в генеративном концепте, не переносились в приложение как фактические данные. Заголовки и содержимое всегда берутся из плана. В проверочном документе использованы факты и доступные изображения исходного Word; описание и требования остаются обычным текстом существующего поля. Цветные status badges не вводились; использованы существующие labels и Badge. Watermark расположен за содержимым, а не как новое брендированное изображение.
